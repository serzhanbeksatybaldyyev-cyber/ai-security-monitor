# Задание 3. Паспорта наборов данных

## 1. Основной набор: UCI SMS Spam Collection

| № | Пункт | Значение |
|---|---|---|
| 1 | Источник | UCI Machine Learning Repository. Авторы: T. A. Almeida, J. M. Gómez Hidalgo |
| 2 | Ссылка | https://archive.ics.uci.edu/dataset/228/ , DOI: 10.24432/C5CC84 |
| 3 | Лицензия | Creative Commons Attribution 4.0 International (CC BY 4.0) |
| 4 | Дата загрузки | 3 ноября 2026 г. (способ получения описан ниже) |
| 5 | Язык | Английский |
| 6 | Объём | 5 574 сообщения, файл 477 907 байт |
| 7 | Классы | `ham` — 4 827 (86,60%), `spam` — 747 (13,40%) |
| 8 | Известные ограничения | Только английский язык. Спам не равен мошенничеству в строгом смысле: в класс входит и обычная реклама. Сообщения собраны примерно до 2012 года, поэтому современные схемы представлены слабо. Много британских платных номеров и сленга. Часть спама собрана с британского форума жалоб, часть ham — из корпуса Сингапурского университета, поэтому модель может уловить различия источников, а не только признаки мошенничества |

**Структура файла.** Текстовый файл UTF-8, разделитель — табуляция, заголовка нет, две колонки: метка и текст. Целевая переменная — метка, она приводится к числу: `ham` → 0, `spam` → 1. Пропусков и строк с неверным числом колонок нет, это проверено скриптом `ml/data/load_sms.py`. Он также сравнивает число прочитанных строк с числом строк в файле (5 574 = 5 574).

**Как получен файл.** Сайт UCI был недоступен из среды, где выполнялась работа. Файл взят из двух независимых репозиториев GitHub: `cshah1995/Spam-Ham-Classifier-Model` и `justmarkham/pycon-2016-tutorial`. Обе копии побайтно одинаковы, а размер, число строк и распределение классов совпадают с описанием авторов.

SHA-256 файла `data/raw/SMSSpamCollection`:

```
7d039a24a6083ed9ef0f806ebad56bbb976e3aeb8de05669173bfdc4996c239d
```

Сверка с официальным архивом выполняется командой `python -m ml.data.verify_source`.

**Как цитировать:** Almeida, T. & Hidalgo, J. (2011). SMS Spam Collection [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5CC84

## 2. Собственный тестовый набор: `data/raw/custom_ru_kk.csv`

| № | Пункт | Значение |
|---|---|---|
| 1 | Источник | Создан для проекта. Все сообщения искусственные |
| 2 | Ссылка | Файл в репозитории: `data/raw/custom_ru_kk.csv` |
| 3 | Лицензия | Учебный набор проекта |
| 4 | Дата создания | 3 ноября 2026 г. |
| 5 | Язык | Русский и казахский |
| 6 | Объём | 156 сообщений: 104 на русском и 52 на казахском |
| 7 | Классы | `0` — безопасное, 78 (50%); `1` — мошенничество, 78 (50%). В каждом языке доля мошеннических ровно 50% |
| 8 | Известные ограничения | Сообщения написаны вручную и могут отличаться от настоящих. Набор маленький. Используется только для теста многоязычности (задание 8), в обучении не участвует. Казахские тексты стоит проверить носителю языка |

**Столбцы:** `id`, `text`, `label`, `language`, `threat_type`, `label_author`. Автор разметки указан в столбце `label_author`.

**Персональные данные.** Реальных телефонов, карт и имён клиентов нет. В ссылках только зарезервированные домены (`.example`, `.test`, `example.com`), телефоны имеют вид `+7 000 000 00 00`, карты замаскированы (`**** 0000`). Это проверяет автоматический тест `tests/test_data.py`.

**Сложные примеры.** Чтобы тест был честным, в безопасный класс намеренно включены сообщения со словами из мошеннических схем: одноразовый код с предупреждением «никому не сообщайте», уведомление о входе в банк, «Выиграли матч 3:1!», «Срочно нужна твоя подпись».
